# agy 샌드박스 실행 전 확인

**무엇**: os 모드에서 agy 리뷰어(`--sandbox`)가 이 머신에서 동작하는지 실행 전에 확인한다.

**왜 밖**: agy에는 모델을 부르지 않는 샌드박스 점검이 없어 매 실행 한도를 쓴다. bwrap 명령으로 대신 재는 것은 agy가 bwrap을 쓰는지 확인하지 못한 추정이다. 실행 중 감지(goldstack-v32 04)가 리뷰 없이 병합하지 않게 막는다.

**다시 볼 조건**: os 모드에서 agy 리뷰가 실행 중 샌드박스 실패로 멈춘 일이 나오면.

결정: goldstack-v32 grill 라운드 1-7, 2-4 (2026-11-12)
