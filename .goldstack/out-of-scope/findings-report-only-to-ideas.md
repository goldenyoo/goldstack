# "보고만" 리뷰 지적의 아이디어 자동 등록

**무엇**: "보고만" high·medium 리뷰 지적(2차 재리뷰의 새 지적 포함)을 마무리가 `.goldstack/ideas/` 파일로 자동 등록한다.

**왜 밖**: goldstack-v44가 뺐다. 자동으로 생긴 67개 중 25개가 버려졌고, 회고가 같은 보고서를 읽고 사람이 고른 것만 올린다(회고 출처 99개 중 버려진 것 4개). 재현된 미수리 결함은 계속 파일이 된다.
