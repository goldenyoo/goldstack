# 마무리 integration 검증 건너뛰기를 끄는 설정

**무엇**: `.goldstack/config.toml`에 마무리 integration 검증 건너뛰기를 끄는 키를 둔다.

**왜 밖**: 건너뛰기는 이번 실행이 받아들인 티켓 검증 결과만 다시 쓴다. 좁은 검증은 grill이 티켓마다 정한다. 지난 22번 integration 검증 실패는 0번이었다.

**다시 볼 조건**: 건너뛴 실행 뒤에 base 검증, CI, 다음 실행에서 전체 시험 실패가 드러나거나, 늘 전체 검증을 원하는 레포가 생기면.

결정: goldstack-v41 grill 라운드 2-1 (2026-11-14)
