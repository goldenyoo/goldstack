# feature 끝 후속 수리 티켓

**무엇**: 다른 미병합 티켓과 파일이 겹쳐 `defer`로 남은 재현된 결함을, feature 끝에 integration 위에서 후속 수리 worker 한 번으로 고친다.

**왜 밖**: 마무리 흐름에 새 상태 전이·재개 경로가 생기는 큰 변경이다. goldstack-v27은 판단 기준을 넓혀(미병합 티켓 `touches` 밖이면 fix) v24 사례를 먼저 푼다.

**다시 볼 조건**: `defer`(재현된 미수리 결함)가 여러 실행에 걸쳐 남고, 사람이 매번 다음 feature로 같은 수리를 하게 되면.

결정: goldstack-v27 grill 라운드 1-4 (2026-11-08)
