# gs remote go 시작 예약

**무엇**: 실행 중 확인과 세션 생성 사이의 경합을 막도록 `/go`가 `gs go` 잠금을 잡을 때까지 이어지는 원격 예약을 둔다.

**왜 밖**: pull 중에 같은 feature를 또 시작할 때만 생긴다. 두 번째 `gs go`는 잠금에 막혀 추가 세션만 뜬다. 재확인은 창을 좁힐 뿐이고 막으려면 새 설계가 필요하다.

**다시 볼 조건**: 같은 feature에 원격 세션이 둘 뜬 일이 실제로 나오면.
