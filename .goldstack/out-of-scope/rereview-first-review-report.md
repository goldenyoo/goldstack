# 첫 리뷰 report 지적의 재판정

**무엇**: 첫 리뷰가 report(보고만)로 분류한 지적도 매 재리뷰가 해소됐는지 판정한다.

**왜 밖**: 첫 리뷰 report 지적은 대부분 일부러 고치지 않은 것이라 판정해도 unresolved가 되고 재리뷰 프롬프트만 커진다. goldstack-v40은 재리뷰가 새로 낸 report 지적(v39 04 F2처럼 같은 원인의 fix 지적과 함께 고쳐졌을 수 있는 것)만 다음 회차에 싣는다.

**다시 볼 조건**: 수정 커밋으로 이미 해소된 첫 리뷰 report 지적이 보고서 "남은 위험"에 남아 사람이 따로 확인한 일이 나오면.
