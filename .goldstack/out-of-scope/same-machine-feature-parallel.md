# 같은 머신에서 feature 나란히 돌리기

**무엇**: 맥미니 안에서 독립 feature 둘을 동시에 돌린다. 원격 실행 로그를 다른 머신으로 옮기는 일도 함께 둔다.

**왜 밖**: 모든 일을 맥미니가 하므로 맥북 동시 실행의 전제가 사라졌다. v14·v15처럼 파일이 겹치면 나란히 못 돌고, 같은 머신의 시험 경합은 재지 않았다. `/retro`를 맥미니에서 돌리니 로그를 옮길 필요도 없다.

**다시 볼 조건**: 서로 파일이 겹치지 않는 feature가 줄을 서서 기다리는 일이 반복되거나, 사람이 맥북을 다시 함께 쓰게 되면.
